# 3-minute demo script
1. (0:00) Open the app. Point out the "Demo: synthetic data and simulated transactions" badge.
2. (0:20) Create Listing: tap "Try guided demo" (800 kg overripe bananas, Pukekohe). Show editable fields, tap "Confirm and publish".
3. (1:00) Matches: show eligible vs restricted. Open "Score factors & formulas". Note transport, economics, CO2e range.
4. (1:30) Restricted card: show verification is required and the transaction button is blocked; click simulated verification.
5. (2:00) Start an eligible exchange. Transactions: step through to Completed. Note "no real funds".
6. (2:40) Dashboard and Impact: completed tonnes and CO2e update once; projected impact is shown separately.
7. (2:55) Profile: notifications, then "Reset demo data".
